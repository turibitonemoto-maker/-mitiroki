# Michiroku 道録

徒歩旅の記録整理と、旅行記づくりを助けるアプリ（開発中）。
移動の記録はズレる前提で、**後から人間が直せること**、そして直した記録が**物語（旅行記）になること**を核にしています。

- 対象: ウォーキング、街歩き、旅行、自転車や車での移動
- プラットフォーム: Android ネイティブが本命。ブラウザ版は閲覧・訂正・物語化・PDF出力用
- 参考: YAMAP

## 主な機能（予定）

1. **移動の記録（GPS）** — 移動方法・寄った場所・滞在時間を記録。GPSがズレても後から訂正できる
2. **感想メモ** — 1人用チャット形式で、時刻つきの写真・文章をその場で投下
3. **費用記録** — レシート／手入力で合計と内訳を表示。訂正も可能
4. **書き出し** — 旅のルートや履歴を PDF / テキストでコピー出力
5. **旅の予定** — 強制力のない予定。確実に行く場所＝チェックポイント、行きたい場所＝サブチェックポイント

## 旅の記録の表示

サムネイル写真 / 旅の題名 / 総移動距離・総時間・費用・日数・消費カロリー / ルートをなぞったマップ / 移動ルート（時間・滞在時間・移動方法） / 場所ごとのコメント記録

## 技術方針

- Android: Kotlin + Jetpack Compose
- 記録: Foreground Service + Fused Location Provider（画面を閉じても記録継続）
- 保存: ローカルファースト（Room / SQLite）＋ Firebase（Auth / Firestore / Storage）で同期
- 地図: 国土地理院タイル（MapLibre / osmdroid を想定）
